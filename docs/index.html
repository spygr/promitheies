Το * στο τέλος λέξης σημαίνει «οτιδήποτε μετά» (φωτοβολταϊκ* βρίσκει φωτοβολταϊκά, φωτοβολταϊκών…). Οι τόνοι και τα κεφαλαία δεν παίζουν ρόλο.
Ρυθμίσεις μόνιμης αποθήκευσης λέξεων-κλειδιών

Για να μπαίνει μια νέα λέξη και στην καθημερινή αναζήτηση (όχι μόνο στο φιλτράρισμα εδώ), το site την αποθηκεύει στο GitHub repo σου. Χρειάζεται ένα fine-grained personal access token μόνο για αυτό το repo, με δικαιώματα Contents: Read and write και Actions: Read and write. Το token μένει μόνο στον browser σου.

Χωρίς token, οι νέες λέξεις ισχύουν μόνο σε αυτή τη συσκευή και φιλτράρουν τα ήδη συλλεγμένα αποτελέσματα.
