# Προκηρύξεις Radar

Κάθε μέρα (GitHub Actions) ψάχνει ΚΗΜΔΗΣ/ΕΣΗΔΗΣ, Διαύγεια και όποια sites βάλεις στο `sources.json`
για τις λέξεις του `keywords.json`, και δείχνει τα αποτελέσματα στο `docs/index.html` (GitHub Pages).

## Στήσιμο (μία φορά)

1. Φτιάξε νέο repo στο GitHub (π.χ. `promithies-radar`) και ανέβασε όλα τα αρχεία αυτού του φακέλου.
2. **Settings → Pages**: Source = *Deploy from a branch*, Branch = `main`, φάκελος `/docs`.
3. **Settings → Actions → General → Workflow permissions**: *Read and write permissions*.
4. **Actions → Καθημερινή αναζήτηση προκηρύξεων → Run workflow** για το πρώτο τρέξιμο.
5. Άνοιξε `https://ΧΡΗΣΤΗΣ.github.io/promithies-radar/`.

## Προσθήκη λέξεων-κλειδιών

- Από το site: γράφεις τη λέξη στο πεδίο και πατάς Προσθήκη.
  - Χωρίς token: ισχύει μόνο στη συσκευή σου και φιλτράρει ό,τι έχει ήδη συλλεχθεί.
  - Με token (Ρυθμίσεις στο κάτω μέρος της σελίδας): γράφεται στο `keywords.json` και ξεκινά νέα αναζήτηση.
- Ή επεξεργάσου κατευθείαν το `keywords.json` στο GitHub.
- `*` στο τέλος λέξης = «οτιδήποτε μετά». Τόνοι και κεφαλαία αγνοούνται.

## Προσθήκη sites (δήμοι, πανεπιστήμια κ.λπ.)

Στο `sources.json`, στη λίστα `sites`, πρόσθεσε `{"name": "Δήμος Χ", "url": "https://…/diagwnismoi"}` με τη σελίδα
που λίστα τις προκηρύξεις τους. Το σκριπτ διαβάζει τους συνδέσμους της σελίδας και κρατά όσους ταιριάζουν στις λέξεις σου.

## Τοπικό τρέξιμο / έλεγχος

```
pip install -r requirements.txt
python scraper/scrape.py --debug
```
Το `--debug` τυπώνει δείγμα της απάντησης κάθε API, χρήσιμο για να προσαρμοστούν τα πεδία.

## Γνωστά όρια

- Τα API του ΚΗΜΔΗΣ και της Διαύγειας γράφτηκαν χωρίς δυνατότητα δοκιμής σε ζωντανά δεδομένα. Αν κάποια πηγή
  εμφανίσει ⚠ στο site, δες το μήνυμα και τρέξε με `--debug`.
- Η σελίδα «Ενεργά έργα» (pwgopendata) είναι εφαρμογή με συνεδρίες και δεν σκανάρεται αξιόπιστα· οι προκηρύξεις
  των έργων καλύπτονται από το ΚΗΜΔΗΣ.
- Ο έλεγχος γίνεται στον **τίτλο** της προκήρυξης, όχι μέσα στα συνημμένα PDF.
